# Changelog

## 1.0.0 - 2026-09-07

- Added New Member Watchlist for reviewing posts from recently registered or low-post-count users.
- Added Duplicate Account Finder using shared registration and last-known IP data, with matching IP values shown to staff who have IP Search permission.
- Added Staff Task Queue with username assignment from configured staff groups, assignment PMs, self-claim, creator editing, full task detail pages, intuitive due-date input, priority, completion notes, done, reopen, button-style actions, and admin-only remove actions.
- Added Staff Action Digest summarizing moderator-log activity over a configurable lookback window.
- Added Staff Tools Snapshot panel on the ModCP home page.
- Added AdminCP yes/no toggles for every Staff Tools module, task assignment PMs, and the ModCP snapshot panel.
- Added activation-time upgrade backfill for missing settings, templates, and the staff-task table.
- Organized AdminCP settings by module with clearer labels and descriptions.
- Moved the ModCP snapshot to the top of the ModCP home page and placed Recent Posts Review above moderator notes.
- Updated plugin metadata and documentation for the 1.0.0 release.
